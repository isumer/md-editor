# SolidMD brand assets

The SolidMD app icon. Use these files as they are: do not redraw, recolour
or crop the icon.

| File | Use |
|---|---|
| `solidmd-icon-1024.png` | master image, 1024 × 1024, transparent background |
| `solidmd-icon-256.png` | README and web pages |
| `solidmd.ico` | Windows (16, 24, 32, 48, 64, 128 and 256 px) |
| `solidmd.icns` | macOS (16 px to 1024 px, including Retina sizes) |
| `png/solidmd-<size>.png` | Linux and other uses, 16 px to 1024 px |
